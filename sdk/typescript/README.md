# @howlerops/trigon-client

Typed client for the Trigon API, generated from `spec/openapi.json`. ESM, no
runtime dependencies, Node 18+.

```bash
npm install @howlerops/trigon-client
```

Also on GitHub Packages (`@howlerops:registry=https://npm.pkg.github.com`,
which needs a GitHub token even for public packages).

Usage: `docs/quickstart.md` in the repository, or
https://howlerops.github.io/trigon/.
