# Trigon Go client

```bash
go get github.com/howlerops/trigon/sdk/go@latest
```

Generated from `spec/openapi.json` by `scripts/generate_sdk.py`; do not edit
`trigon.go` by hand. Standard library only. Usage and the hosted-deployment
headers: `docs/quickstart.md`. `go run ./cmd/smoke <base url>` drives a live
gateway, as `tests/test_sdk.py` does in CI.
